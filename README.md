# IsoWriter — Total Commander WFX Plugin

**IsoWriter** — плагин файловой системы (WFX) для Total Commander, предназначенный для прямой побайтовой записи (Raw / DD Write) дисковых образов (`.iso`, `.img`, `.raw`, `.bin`) на USB флеш-накопители и карты памяти (аналог функционала *ROSA Image Writer* и *balenaEtcher*).

---

## Возможности

1. **Интеграция с Total Commander**:
   - Плагин отображается в «Сетевом окружении» (`Network Neighborhood`) под именем **`ISO USB Writer`**.
   - Отображает только реальные съёмные USB-диски в виде папок:  
     `[USB 2] Kingston DataTraveler 3.0 (29.8 GB) [E]`
2. **Безопасность**:
   - Системный диск (где установлена Windows) аппаратно исключён из списка и защищён от записи.
   - Фиксированные внутренние NVMe/SATA диски игнорируются (`BusTypeUsb` / `RemovableMedia` фильтр).
   - Проверка прав Администратора перед записью.
3. **Анализ структуры ISO**:
   - Автоматическое определение типа загрузки: **Hybrid ISO (UEFI + Legacy BIOS MBR)**, **UEFI (GPT/EFI)**, **Legacy MBR / El Torito**, либо **Standard ISO 9660**.
4. **Диалоговое окно подтверждения перед записью**:
   - Показывает подробную информацию об образе и целевой флешке.
   - Защита от случайного нажатия: кнопка «Записать» активируется только после установки галочки подтверждения.
5. **Надёжная запись и верификация**:
   - Блокировка и размонтирование существующих томов (`FSCTL_LOCK_VOLUME`, `FSCTL_DISMOUNT_VOLUME`).
   - Поблочная запись буфером 1 МБ с выравниванием по сектору (`FILE_FLAG_NO_BUFFERING | FILE_FLAG_WRITE_THROUGH`).
   - Отображение прогресса в стандартном окне копирования Total Commander (с возможностью отмены).
   - Опциональная побайтовая верификация после записи.
   - Автоматическое обновление таблицы разделов в ОС (`IOCTL_DISK_UPDATE_PROPERTIES`, `SHChangeNotify`).

## Установка

1. Откройте Total Commander.
2. Откройте файл **`IsoWriter.zip`** (двойным кликом или Enter) прямо в Total Commander.
3. Total Commander распознает `pluginst.inf` и предложит установить плагин: нажмите **Да**.
4. Перезапустите Total Commander от имени Администратора (для доступа к `\\.\PhysicalDriveN`).

---

## Использование

1. Перейдите в панели Total Commander в **Сетевое окружение** (`Network Neighborhood`) -> **ISO USB Writer**.
2. Вы увидите список подключенных USB-накопителей.
3. Перетащите или скопируйте (клавишей **F5**) нужный `.iso` или `.img` файл в папку выбранного USB-диска.
4. В появившемся диалоговом окне проверьте информацию, отметьте галочку подтверждения и нажмите **Записать**.

## Сборка из исходников

Для сборки требуются:
- Visual Studio 2022 (MSVC C++17)
- CMake 3.15+

Скрипт `build.bat` автоматически компилирует обе версии и собирает релизный zip:
```cmd
build.bat
```

Результат:
- `dist\IsoWriter.wfx64` (64-битный плагин)
- `dist\IsoWriter.wfx` (32-битный плагин)
- `IsoWriter.zip` (пакет установки)
